# Intrinsic — complete package

This zip contains the full app, including the sample report and screenshots.

## Start it (Windows)

Double-click **`start.bat`** — it starts the server and opens your browser.

Or in PowerShell:

```powershell
cd intrinsic
.\start.ps1
```

Then open <http://127.0.0.1:8765>.

## Start it (macOS / Linux, or any OS with Python 3.10+)

```bash
cd intrinsic
python3 server.py --open
```

No installs, no API keys, no build step — the server uses only Python's standard library.

## A note on the server

The app runs **locally on your machine** while `start.bat` (or the Python command) is open.
If the page says "page load failed", the server has stopped — start it again.

Closing the black console window stops the server.

## Reporting a problem

If something doesn't load, check the console window for errors and note which ticker
you were viewing. The footer of each analysis shows exactly which financial periods it used.
